# pflegegrad-media

Öffentlicher Ablageort für die fertigen Medien des Instagram-Kanals [@pflegegrad_](https://www.instagram.com/pflegegrad_/).

Über GitHub Pages bekommt jede Datei einen festen öffentlichen Link, den Metricool zum Einplanen der Beiträge braucht.

Hier liegen nur fertige, freigegebene Beiträge, die ohnehin auf Instagram erscheinen. Keine Skripte, Entwürfe oder Falldaten.

Alle Inhalte sind mit KI erstellt und fachlich von einem Menschen geprüft.

## Aufbau

```
reels/<Datum>-<Thema>/reel.mp4
reels/<Datum>-<Thema>/cover.png
karussells/<Datum>-<Thema>/01.png …
```
